# 电力 SCADA 演示系统开发方案（PowerGrid SCADA Demo）

## 1. 目标与定位

面向面试展示，5 分钟内让面试官看到两件事：

| 维度 | 体现点 |
|---|---|
| **业务知识** | 四遥（遥测/遥信/遥控/遥调）、SOE、选择-返校-执行遥控、五防闭锁、拓扑着色、挂牌、事故追忆、越限告警、品质位、总召唤 |
| **技术能力** | 真实工业规约（IEC 60870-5-104 / Modbus TCP）、实时数据管道、时序库、WebSocket 推送、SVG 一次接线图、容器化部署、CI/CD、测试 |

核心思路：**不造假数据**。仿真子站用潮流计算产生电气量，经 IEC 104 规约上送；SCADA 主站按真实链路采集、处理、展示、控制。

## 2. 总体架构

```
┌──────────────────── VPS (docker compose) ────────────────────┐
│  Caddy (HTTPS/反代 + 前端静态) ──► api (FastAPI, REST + WS)    │
│                                     │   ▲                     │
│                                     │   │ Redis 实时库/事件总线 │
│                                     ▼   │                     │
│                               TimescaleDB   fep (前置采集)     │
│                                              IEC104/Modbus 主站│
│                                                  │ ▲          │
│                                                  ▼ │ 遥控      │
│                                    rtu-sim (仿真子站)          │
│                                    pandapower 潮流 + 保护逻辑   │
└───────────────────────────────────────────────────────────────┘
```

对应真实调度系统的 **厂站 RTU → 前置 FEP → SCADA 服务器 → HMI** 四层结构。

## 3. 技术选型

| 模块 | 选型 | 理由 |
|---|---|---|
| 仿真子站 | Python + pandapower + c104(lib60870) + pymodbus | 交流潮流保证功率平衡、电压降符合物理规律 |
| 前置采集 | Python asyncio + c104 主站 + pymodbus | 规约解析、死区、品质位、变位、时标 |
| 实时库 | Redis（Hash 实时值 + Stream 事件） | 毫秒级读写，相当于传统实时库 |
| 历史库 | TimescaleDB | hypertable、连续聚合、压缩；同时存关系模型 |
| 后端 | FastAPI + SQLAlchemy 2 + Pydantic v2 | 异步、OpenAPI 自文档 |
| 前端 | Vue 3 + TS + Vite + Pinia + Naive UI + ECharts | 一次接线图为 SVG 自绘图元 |
| 网关 | Caddy | 自动 HTTPS |
| 部署 | docker compose + GitHub Actions → GHCR → VPS | |
| 测试 | pytest / Vitest / Playwright | |

## 4. 电网模型

110kV 内桥接线（2 回进线、2 台 50MVA 主变）+ 10kV 单母分段（F01 工业、F02 居民、F03 商业、F04 光伏、C1 电容器、分段开关）。

- 设备：断路器、隔离刀闸、接地刀闸、主变（OLTC 档位）、PT/CT、电容器、光伏
- 典型日负荷曲线 + 随机扰动，光伏按日照曲线；支持加速时钟
- 模型命名参照 **IEC 61970 CIM**（Substation / VoltageLevel / Bay / Breaker / Disconnector / ConnectivityNode / Analog / Discrete）

| 类型 | 104 类型标识 | 示例 |
|---|---|---|
| 遥测 | M_ME_NC_1 / M_ME_TF_1 | 母线电压、线路 P/Q/I/cosφ、油温、频率 |
| 遥信（双点） | M_DP_TB_1 | 断路器/刀闸位置 |
| 遥信（单点） | M_SP_TB_1 | 保护动作、重合闸、事故总、SF6 低气压 |
| 遥控 | C_DC_NA_1（SBO） | 断路器分合 |
| 遥调 | C_RC_NA_1 / C_SE_NC_1 | 主变升降档、光伏有功设定 |
| 电度 | M_IT_NA_1 | 正/反向有功电量 |

## 5. 功能模块

1. **数据采集**：STARTDT、总召唤、时钟同步、电度召唤、k/w 窗口、t1/t2/t3；品质位 IV/NT/SB/OV；死区；通道监视；**报文监视窗口**；Modbus 接入逆变器
2. **实时处理**：四级限值 + 回差越限告警；事故变位/正常变位区分；SOE 按设备时标（ms）排序；计算量；人工置数/封锁
3. **一次接线图**：SVG 图元库；电源点 BFS 拓扑着色（按电压等级配色、停电灰、接地标识）；潮流箭头；挂牌；品质可视化
4. **遥控与五防**：选择-返校-执行（超时撤销）、双人监护、可配置五防规则、审计日志
5. **告警与事件**：分级告警窗、音响/闪烁/确认、光字牌、**事故追忆 PDR 回放**
6. **历史与报表**：趋势、日负荷曲线、电压合格率、主变负载率、Excel 导出
7. **故障注入面板**：瞬时故障重合成功、永久故障后加速、主变跳闸备自投、光伏电压越限调档、通道中断
8. **AI 增强（可选）**：负荷预测（LightGBM）、遥测异常检测、告警根因归并 / LLM 事故简报

## 7. 数据库要点

模型表（substation / voltage_level / bay / equipment / measurement）；时序 `analog_history` hypertable + 15min 连续聚合 + 7 天压缩；事件表 `soe`(device_ts, recv_ts)、`alarm`、`control_log`、`pdr_snapshot`、`tag`。

## 8. 实时链路

rtu-sim →104→ fep →(死区/品质)→ Redis HSET + XADD → api（告警/SOE 处理，批量 COPY 写库）→ WebSocket 按画面订阅、100ms 合帧增量推送。

## 9. 安全

JWT + RBAC（访客只读 / 调度员 / 监护员 / 管理员）；场景每小时自动重置；遥控限流 + 审计；VPS 只开 80/443，104 端口只在内网（对应"安全分区"）。

## 11. 5 分钟演示脚本

1. 架构图：四层结构、真实 104 规约
2. 接线图：拓扑着色、潮流、负荷曲线
3. 注入 F02 永久故障：SOE 毫秒序列 → 告警 → 线路变灰 → PDR 回放
4. 遥控：先演示五防拒绝，再走选择→返校→监护→执行
5. 报文监视：104 报文解析
6. 部署与 CI
